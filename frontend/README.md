# Sentinel AI Frontend

React and Vite frontend for the Sentinel AI infrastructure inspection workflow.

## Setup

```powershell
cd frontend
npm install
```

Create a local `.env.local` file when needed:

```text
VITE_API_URL=http://localhost:8000
```

## Run

```powershell
npm run dev
```

Build for production:

```powershell
npm run build
```
